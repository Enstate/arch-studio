# General guidance

Arch writes this guide into the BUILDERS.md of every project of this kind, after the core standards. Its source is packages/project-tools/src/rules.ts: change it there, and a test keeps this copy equal.

The user said this project is none of the listed kinds, for example a pavilion, a bridge, a stage set, an installation or an exhibition stand. Decide from the brief and references which parts are built like a building, with walls, openings and storeys, and which are open ground, and follow the guide for the kind each part resembles. Use the plan contract as it stands: walls only where something stands, rooms for any floor area with a finish, ground:true models for terrain, levels for anything stacked and stairs pieces for flights. Ask the user before a choice that changes what the project is.
